# Contribuyendo a OfiAI

## Proceso de Contribución

1. Fork del repositorio
2. Crear una rama descriptiva: `git checkout -b feat/matching-ia`
3. Seguir los estándares de código (ver `CodingStandards.md`)
4. Escribir tests para la nueva funcionalidad
5. Hacer commit siguiendo convenciones: `feat: descripción en español`
6. Abrir un Pull Request con descripción detallada

## Reglas del Proyecto

- **Idioma**: Comentarios y mensajes en Español Latino
- **TypeScript**: Tipado estricto, sin `any`
- **Tests**: Cobertura mínima de 70% para nuevos archivos
- **Documentación**: Actualizar docs/ si se cambia arquitectura
